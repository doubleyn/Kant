### 원격 레포지토리와 연결 및 푸시

```bash
git remote -v
git remote add origin {git 주소}
# origin  https://github.com/doubleyn/Kant.git (fetch)
# origin  https://github.com/doubleyn/Kant.git (push)

# 최신화
git pull (= git fetch + git merge)

# 상태 확인
git status (빨강/초록)

# 파일 수정/저장 후 Working Directory -> Staging Area로
git add .

# 커밋 추가
git commit -m "feat: dddd"

# 푸시
git push origin main # origin이라는 alias에 main 브랜치에 올린다.
# -u 는 가급적 쓰지 말자
```
