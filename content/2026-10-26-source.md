# Git & GitHub

---

- Git이란
  - VCS; Version Control System 형상 관리 도구
  - 리누스 토발즈, 2005
  - 중앙집중형이 아니라 분산형(DVCS)
- GitHub란
  - 원격 저장소, 2008년 서비스 시작
  - 2018년 MS 인수
  - 유사 서비스: GitLab, Bitbucket
  - binary 파일(대용량)은 <code>lfs</code> 명령어 사용

# CLI 실습

---

<image source="notion-file-block://405acd67-b1e7-80a2-9520-d0164813d6fa/b3faa13d-f35f-41a5-93a2-4e043a908f52?space_id=cd1acd67-b1e7-81df-89d8-000371d242cc&name=image.png">
Terminal은 명령어를 주고받는 공간, Shell은 명령어를 해석하고 실행하는 주체
</image>

- 터미널 닫기

```shen
exit
```

- 터미널 기본 프로필 설정 → Git Bash

<image source="notion-file-block://405acd67-b1e7-8070-bdbc-e45b72814099/7da50c66-08f9-4e5f-80e9-6efb6a907297?space_id=cd1acd67-b1e7-81df-89d8-000371d242cc&name=image.png" />

---

- Git Bash 기본 명령어들

```bash
whoami
pwd (print working directory)
ls (list)
ls -al (all)
ls -alh (human readable; 파일 사이즈 단위 표시 K, M 등)  
clear
mkdir (make directory)
cd (change directory)
```

<p />

<image source="notion-file-block://405acd67-b1e7-80b6-966c-eb88dd443d5a/1c7e38c0-570f-4037-ae43-a8d56e8f4633?space_id=cd1acd67-b1e7-81df-89d8-000371d242cc&name=image.png" />

- <code>d</code>: directory 폴더
- <code>l</code>: link 파일
- <code>-</code>: 일반 파일
- <code>rwxrwxrwx</code>
  - 소유자(owner)/그룹/기타(other) 순서
  - read write execute (읽기/쓰기/실행) 권한
  - unix가 다중 접속을 허용하므로 사용자별 권한 부여

<p />

- <code>~/</code> 홈 디렉토리
- <code>./</code>  현재 디렉토리
- <code>../</code> 상위 디렉토리

<p />

- 명령어 이력 확인
  - 맥에서는 <code>ctrl + r</code>

```bash
history
```

---

- [ ] 윈도우에서도 oh-my-zsh 사용 가능 (터미널 꾸미는 도구)

---

- 입력한 명령어 한번에 지우기: <code>ctrl + u</code>
- 단어 단위로 지우기: <code>ctrl + w</code>

<p />

- <code>tab</code> 으로 자동완성 (한 단어만 치고)

<p />

- <code>cd ~</code> 홈 디렉토리로 이동
- <code>cd -</code> 직전 폴더로 이동

---

- 파일 생성 <code>touch README.md</code>
- 현재 쓰고 있는 쉘 종류 확인

```bash
echo $SHELL
# /usr/bin/bash
```

- echo로 파일에 문자 넣기
  - <code>></code> 는 리다이렉션 의미

```bash
echo "Hello World" > README.md
```

- 파일 내용 확인 (간단한 ASCHII)

```bash
cat README.md
```

<p />

- <code>></code> 하나는 overwrite
- <code>>></code> 두개는 append
