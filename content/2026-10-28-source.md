- <code>git clone {레포지토리 Git 주소}</code>

```bash
# 스테이징에 추가
git add . # 현재 폴더 기준 수정사항
git add -A # 해당 레포지토리 수정사항에 전역적으로 접근

# 리셋 - 해당 해시 커밋으로 되돌아간다
git reset --soft {hash} #  staging area에 added된 상태까지
git reset --mixed {hash} # (default) working directory 상태까지
git reset --hard {hash} # 작업물 전부 날리기
```

### Git Branch

---

```bash
# 브랜치 목록 확인
git branch
git branch --list

# 브랜치 생성
git branch feature/login
# 브랜치 이동
git checkout feature/login

# 브랜치 생성+이동 (동시에) ⭐
git checkout -b feature/login

# 브랜치 삭제
git branch --delete feature/login
git branch -D feature/login # 강제로 제거 (-D)
```
