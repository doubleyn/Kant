01 · del 키워드

대상에 따라 달라지는 del의 동작


# ① 변수 이름 삭제
x = 10

# ② 리스트 요소 삭제
numbers = [10, 20, 30]
del numbers[0]

# ③ 딕셔너리 요소 삭제

del person["name"]
구문 · 행에 올려 보세요내부 동작
del x현재 스코프에서 이름 x의 바인딩 제거
del numbers[0]numbers.__delitem__(0)
del person["name"]person.__delitem__("name")

리스트와 딕셔너리는 모두 __delitem__()이라는 특수 메서드를 구현한다.

01 · del 키워드

del은 객체가 아니라 이름의 바인딩을 지운다

del a 줄에 올려 보세요
a = [1, 2, 3]
b = a

del a

print(b)  # [1, 2, 3]
print(a)  # NameError

del a 실행 전 · 마우스를 올리면 실행 후del a 실행 후

a [1, 2, 3] b

이름 a와 b가 같은 리스트 객체를 가리킨다. 이름 a만 사라지고, 리스트 객체는 b가 계속 참조하므로 그대로 남는다.

02 · get() 동작

get()은 키가 없어도 오류 없이 값을 준다

key가 존재하면

해당 키의 값을 반환

menu.get("coffee") → 4000

key가 없으면

default 값을 반환

menu.get("cake", 5000) → 5000

default를 생략하고 key가 없으면

None 반환

menu.get("cake") → None


print(menu)
# {'coffee': 4000, 'tea': 4500}

# menu["cake"]
price = menu.get("cake", 5000)
print(price)  # 5000

print(menu)
# {'coffee': 4000, 'tea': 4500}

03 · Set의 remove와 discard

없는 요소를 지울 때, 오류를 낼 것인가

remove()

요소가 없으면 KeyError

반드시 존재해야 하는 요소를 제거할 때

요소가 없다는 사실을 오류로 감지하고 싶다면 remove()가 적합하다.


fruits.remove("grape")
# KeyError: 'grape'

마우스를 올려 실행 결과 보기

discard()

요소가 없어도 오류 없음

있을 수도, 없을 수도 있는 요소를 제거할 때

네트워크 문제로 연결 종료 이벤트가 중복 발생해도 discard()로 안전하게 처리할 수 있다.


fruits.discard("grape")
# 아무 일도 일어나지 않음

마우스를 올려 실행 결과 보기

03 · Set의 remove와 discard

오류 없이 안전하게 제거하기


# 집합
fruits.discard("grape")  # 요소가 없어도 오류 없음

# 딕셔너리의 경우
menu.pop("cake", None)  # 키가 없어도 오류 없음
참고

menu["cake"]는 오류가 나지만, menu.get("cake")는 값이 없어도 오류 없이 None을 반환한다.

04 · Set 자료구조에서 순서 ⭐

중복을 제거하는 세 가지 방법

print 줄에 마우스를 올려 결과 보기
# 원시 데이터
raw_emails = ["a@sparta.com", "b@sparta.com", "a@sparta.com"]

# 집합으로 중복 제거 - 집합은 순서 보장 X
print(list(set(raw_emails)))

# 중복을 제거하면서 원본 순서 보장하기
print(list(dict.fromkeys(raw_emails)))

# 중복을 제거하면서 정렬하기 - sorted
print(sorted(set(["c", "d", "a", "f", "a"])))

04 · Set 자료구조에서 순서 ⭐

순서가 필요하면 dict.fromkeys()

코드 · 행에 올리면 결과중복 제거원래 순서 유지
