# FastAPI 채용노트

`index.html`을 열면 경력별 공고 목차를 볼 수 있습니다. `jobs/001.html`부터 `jobs/151.html`까지 각 공고를 독립 HTML로 분리했습니다. 모든 자산은 로컬 파일이며 인터넷 연결 없이 목록과 상세 내용을 볼 수 있습니다. 원문 공고 연결에는 인터넷이 필요합니다.

- 151개 공고 / 119개 회사. 제공된 CSV의 모든 행과 두 번째 원문 링크까지 보존합니다.
- 형광 노랑 `#eaff00`과 흑백 중심의 반응형 UI.
- 회사·포지션·지역 검색, 최소 경력별 목차, 지역·FastAPI 언급 필터, 경력 그룹 내 회사명·마감일 정렬.
- 관심 공고는 브라우저의 localStorage에 저장됩니다. `file://`에서 파일별 저장소를 분리하는 브라우저에서는 로컬 서버 사용을 권장합니다.
- 날짜와 FastAPI 언급은 CSV 원문 기준입니다. 최신 채용 여부를 별도로 조회하거나 상세 업무 내용을 추가하지 않았습니다.

데이터를 변경한 뒤 HTML 재생성:

```powershell
node build.mjs
```

`jobs.json`이 생성용 입력이고 `jobs.csv`는 내려받기용 원본입니다. 데이터 수정 시 두 파일을 함께 갱신하세요.

로컬 미리보기:

```powershell
node serve.mjs
```

출력되는 주소를 브라우저에서 엽니다. `Ctrl+C`로 서버를 종료합니다.
